# Huayra

Public fork of [zanneth/huayra](https://code.zanneth.com/zanneth/huayra) — a dense AI coding-agent frontend.

**Credit.** Original design, CEF desktop host, OpenCode integration, and Codex Micro support are by [zanneth](https://code.zanneth.com/zanneth), MIT License, copyright 2026 zanneth.

**This fork** adds a hostable web console, Grok, Cursor, OpenCode 2, OMP, Pi, Prime Intellect, custom engines, a passphrase gate, and mascots.

## Playground

- Grok VM preview: the App Builder live app
- Vercel static demo: project `huayra-playground`
- Repo: https://github.com/qxlsz/huayra

Sample console / mascot / mobile shots live in the Grok app under `/docs/console.jpg`, `/docs/mascots.jpg`, `/docs/mobile.jpg`.
